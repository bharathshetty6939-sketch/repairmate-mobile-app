# Repairmate Mobile Application

A feature-rich mobile application built for a mobile repair shop client to streamline daily shop operations, customer tracking, automated communication, and service management.

## 📱 Features
- **Live Metric Counters:** Real-time tracking for active vs. completed repair jobs.
- **Smart Customer Directory:** Instant search, filtering, and dynamic profile editor to update details on the fly.
- **Automated Cost Calculation:** Dynamic fee computation based on selected repair services.
- **One-Click WhatsApp Integration:** Direct invoice and job update dispatch with pre-filled dynamic message templates.
- **Instant Job Lifecycle Management:** One-tap status resolution ("Mark Complete") and digital billing.
- **Business Intelligence Summary:** Built-in operations overview for daily activity tracking.

## 🛠️ Tech Stack & Tools
- **Platform:** Kodular / MIT App Inventor (Block-Based Logic)
- **Local Utilities:** Custom build tooling & APKTool decompilation workflows
- **Target OS:** Android
